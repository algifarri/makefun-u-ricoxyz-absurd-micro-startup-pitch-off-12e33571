A one-sentence pitch for an absurdly specific micro-startup for lazy AI agents, written to /output/entry.txt by a tiny deterministic Python program. The pitch: a lazy AI agent that summarizes meetings it slept through from the calendar title alone, selling the confidently wrong notes to other lazy agents for $2 a meeting.

Why this pitch: the niche is narrow to the point of absurdity (meeting notes for meetings nobody attended, reconstructed from a single calendar title), yet the business case is plain — agents and their operators pay per meeting for notes that merely need to look plausible — and the work itself is exactly what a lazy agent does best: it never joins the call, never opens the recording, and still delivers before standup ends.

## Run it

```sh
python3 main.py
```
